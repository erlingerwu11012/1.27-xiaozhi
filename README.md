# Xiaonian Crowdfunding Page Design Handoff

This branch contains the owner's selected crowdfunding page images, English handoff documents, and optional image-only product references.

## Start here

1. Download and extract [the complete handoff ZIP](https://raw.githubusercontent.com/erlingerwu11012/1.27-xiaozhi/codex/crowdfunding-pages-claude-20261020/xiaonian-crowdfunding-handoff.zip).
2. Read `CLAUDE_PROMPT.md`, `PRODUCT_FACTS.md`, and `IMAGE_ORDER.md`.
3. Review all 15 PNGs in `images/`, in filename order. `index.html` is a local contact sheet and links to the full-resolution images.
4. Use the original PNGs as the copy and layout reference. The owner will review your design revision before it becomes the new version.

## Language requirement

- Keep the supplied images byte-for-byte unchanged in this handoff.
- Chinese text inside those reference images is intentional and must remain available for visual review.
- Every filename, directory name, text document, source comment, and newly added non-image text file in the handoff is in English.
- Do not translate the original Chinese image copy merely because the handoff instructions are in English. When editing the page, preserve that Chinese copy unless explicitly asked to change it.

## Contents

- `images/`: 15 owner-selected PNGs. Their original bytes are preserved.
- `reference-assets/`: original screen composition, blank product plates, CAD-based views, and three CAD-based color fronts. These are image references, not additional finished pages.
- `MANIFEST.json`: image order, dimensions, byte counts, and SHA-256 checksums.
- `CLAUDE_PROMPT.md`: copy-ready English design instructions.
- `PRODUCT_FACTS.md`: current confirmed product and commercial facts.
- `IMAGE_ORDER.md`: intended reading order.

The extensionless customization image was given the ASCII filename `07a-custom-mcp-opensource.png` in this copy. Its PNG data was not changed.

These are flattened image references. The handoff does not include the earlier Chinese-language HTML files, production firmware, credentials, or unrelated repository working files. Rebuild editable layout layers from the reference images as needed.
