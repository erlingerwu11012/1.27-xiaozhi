# 小念控制台 · 主界面视觉原型 v1

这是 manager-web 主界面（智能体首页）的独立静态原型，用于确认视觉方向。

- 不修改原 Vue 源码，不连接任何接口，不部署，不推送 GitHub。
- One-API 与移动端不在本轮范围内。

## 本地打开

方式一：直接双击 `index.html`，在 Chrome、Edge 或 Safari 中打开。不需要联网，也不需要安装任何东西。

方式二：用本地静态服务（可选）：

```sh
cd xiaonian-console-prototype
python3 -m http.server 8090      # 然后打开 http://localhost:8090/
```

页面右上角的“预览身份”可以在 **普通用户 / 管理员** 之间切换，用来对比两种身份的导航差异。它只是原型里的切换开关，不是权限机制。

## 已实现的交互

- **搜索**：按智能体名称、设备 MAC、设备型号或备注搜索，命中的文字会高亮。
- **筛选**：全部 / 已绑定设备 / 未绑定，按钮上显示各自的数量。
- **视图**：卡片和列表两种视图。列表视图会把右栏移到下方，便于一行看完一个智能体。
- **添加设备**：两种方式。
  - 6 位验证码绑定：只能输入数字，不足 6 位会报错，可以选择绑定到哪个智能体。
  - 手动添加：设备类型、固件版本、MAC 都要填，MAC 格式不对会报错。
  - 另外有“恢复设备连接”。
- **添加智能体**：用简化表单占位，正式版沿用原“唤醒向导”的多步流程。
- **配置角色面板**（右侧抽屉），字段与 `roleConfig.vue` 一致：
  - 助手昵称、它对我的称呼
  - 角色模版：6 个预设，来自 `personaPresets.js`
  - 角色介绍（带字数统计）
  - 语言编码、交互语种
  - VAD / ASR / LLM / VLM / Intent / 记忆模式 / TTS / 音色
  - 聊天记录上报
  - 重启生效提示
  - 保存前会校验昵称不能为空
- **聊天记录**：记忆模式为“无记忆”时这一项不可用，点击时说明原因，与原 `DeviceItem.vue` 的行为一致。
- **设备管理**：可以按智能体筛选、搜索、改备注（最多 64 字）、解绑（需要确认）；有“视觉资源”入口。
- **删除智能体**：需要确认，并提示名下有几台设备会失去关联。
- **其他入口**用同一风格的占位页，写明原路由和需要保留的业务流程：人员身份、视觉角色、壁纸包、官方语音、知识库、充值套餐、账单记录，以及全部管理员页面。
- **基础可用性**：Esc 关闭抽屉和弹窗；弹窗打开时 Tab 键不会跳出弹窗；键盘焦点有可见的焦点环；系统开启“减少动态效果”时关闭动画；宽度 900 px 以下侧栏收起为抽屉。

所有“保存 / 绑定 / 删除 / 解绑”只改动本页内存中的演示数据，提示文字会写明“未提交到服务器”。刷新页面后恢复初始演示数据。

## 设计取舍

1. **导航从顶栏改为左侧栏，按“我的小念 / 屏幕与声音 / 资料 / 账户 / 管理员”分组。** 原顶栏有 8 个一级入口和 11 项的“参数字典”下拉。现在管理员的 11 项再分成“记忆与习惯”“系统参数”两个可折叠子组，普通用户完全看不到管理员组。
2. **去掉欢迎横幅。** 页面直接从智能体列表开始，标题下方用一行汇总“N 个智能体 · N 台设备已绑定”。旁边的问号说明“已绑定 ≠ 在线”。
3. **卡片用真实内容区分彼此，而不是装饰。** 每张卡片列出它绑定的设备（备注或型号 · MAC · 最后对话）；没有设备时显示“还没有绑定设备 · 绑定设备”。模型参数放在浅底的定义列表里，与下方的操作按钮分开。
4. **删除从图标行改为卡片右上角的轻量图标按钮**，并加了确认弹窗。“查看人设”的提示框改为直接在卡片上显示两行角色介绍。
5. **右栏放余额、绑定新设备和常用入口**，并始终标注“演示数据”。宽度不够时右栏移到列表下方。
6. **设备管理页不显示“在线 / 离线”**，因为设备列表接口没有实时在线字段。页面上用提示条说明了这一点。
7. **“视觉角色”与“配置角色”在文案上明确区分。** 配置面板副标题写明“人设与模型设置（LLM 行为），与屏幕上的视觉角色无关”。
8. **字体为子集化的 Noto 字体，打包在原型里**，因此在任何电脑上显示一致。正式接入 Vue 时，可以改为完整字体或系统字体栈。

## 自动检查

```sh
pip install playwright==1.55.0          # 使用本机已有的 Chromium；路径在脚本中设置
python3 tools/check.py                  # 输出到 screenshots/ 与 screenshots/qc-report.json
```

当前结果：**54 / 54 通过**。检查内容包括：

- 1440、1280 与 390 宽度下的字体加载
- 页面没有横向溢出，文字没有被意外裁切
- 搜索、筛选、视图切换
- 配置面板的打开、校验、保存与 Esc 关闭
- 添加设备的两种方式及各自的校验
- 添加与删除智能体
- 设备筛选、备注、解绑
- 普通用户与管理员的导航差异
- 7 个占位页与用户菜单
- 键盘焦点
- 整个过程中没有任何 JS 错误或警告

脚本中的 Chromium 路径为本次云端环境的路径，在本机运行前需要修改。
