# 功能清单

下面列的都是**原有功能**在改版后的位置与交互；改版没有增加新的业务功能。所有条目都只在演示数据下验证过，真实接口未联调。

## 通用

- 分组侧栏：我的小念 / 屏幕与声音 / 资料 / 账户；管理员分组只对管理员显示。窄窗口（≤960px）侧栏收起为抽屉。
- 顶栏：面包屑、**添加设备**、余额（正常 / 可能不是最新 / 暂不可用，点击进入充值；菜单里可进入账单）、账户菜单（语言、修改密码、退出登录）。
- 所有列表：加载中、空数据、无搜索结果、加载失败（可重试）四种状态；删除 / 解绑等危险操作二次确认；表单校验、保存、取消、重置。
- 普通用户进入管理员页面：显示“没有访问权限”；记忆管理、记忆设置、习惯管理沿用原守卫跳回首页。
- 中文 / English 切换（繁体中文、德语、越南语沿用原文案与覆盖文案）。
- 演示模式（仅 mock 构建）：切换演示身份、数据场景（正常 / 空数据 / 服务异常）、余额状态，重置演示数据。

## 账户

- 登录：用户名密码 + 图形验证码；手机号 + 短信验证码（按后台配置显示）。
- 注册、找回密码（短信验证码）。
- 修改密码、退出登录。

## 我的小念

- **我的智能体（首页）**：卡片 / 列表视图切换（记住选择）；按名称、设备备注、MAC 搜索；按绑定状态筛选（带数量）；统计智能体数、已绑定设备数，在线设备显示“暂不可查”；卡片显示角色介绍、语言模型、音色、记忆、绑定设备与最近对话；入口：配置角色、设备、人员身份、聊天记录（无记忆时不可用并说明原因）、删除。
- **添加智能体**：三步向导（名字与称呼 → 音色与记忆 → 人格：模板 / 自己写 / 模组、塔罗、盲盒生成）；没有智能体时自动打开。
- **添加设备**（顶栏、首页卡片、设备管理）：6 位验证码绑定、恢复设备连接、手动添加（型号、固件版本、MAC 校验）。
- **配置角色**：称呼、人格模板与人格文字；语音识别、语言模型与功能（MCP / 插件参数）、视觉模型、记忆模式与聊天记录上报方式、语音合成与音色试听；放弃修改、恢复默认模型、保存配置。
- **聊天记录**：会话列表分页加载、消息与语音播放、下载本会话 / 本会话及之前 20 个。
- **设备管理**：按智能体查看绑定设备；搜索；行内修改备注；单个 / 批量解绑；分页；设备图片资源（上传、按类型筛选、同步到设备）。
- **人员身份**：成员增删改名；人脸（上传照片、使用设备抓拍、绑定已有人脸、解绑）；声纹（录入 / 重录、绑定已有声纹、解绑、样本试听）；搜索与“未绑人脸 / 未录声纹”筛选。

## 屏幕与声音

- **视觉角色 / 壁纸包**：搜索、卡片浏览、查看演示视频、下载到设备（选择设备、任务进度、设备忙提示）；管理员发布（上传识别、校验、发布）。
- **我的音色**：音色设计（描述 + 试听文本）、音色复刻（上传 / 录音）、试听、重命名、删除。
- **配音工作台**：文本编辑与语气标签、选择音色（官方 / 我的设计 / 我的复刻）、语言与方言、音量、语速、导出格式、生成配音、我的配音（播放、下载、再次编辑、删除）。

## 资料

- **知识库**：新建、编辑、启用 / 停用、搜索、单个 / 批量删除。
- **文档**：上传（含批量）、解析、解析状态自动刷新、查看切片、召回测试、单个 / 批量删除。

## 账户（充值与账单）

- **充值套餐**：余额、套餐选择、支付（mock 模式为“演示付款确认”，可模拟成功 / 失败 / 取消）、用量趋势、硬件调用明细。
- **支付结果**：订单状态查询与到账提示。
- **账单记录**：充值订单、调用账单、分页、查看订单。

## 管理员

- **用户管理**：搜索、分页、批量启用 / 禁用 / 删除、重置密码（结果弹窗可复制）。
- **模型配置**：按类别查看模型、搜索、启用 / 停用、设为默认、新增 / 修改 / 复制 / 删除；语音合成模型的音色管理（新增、行内编辑、批量删除、试听）。
- **参数管理**：搜索、新增 / 编辑 / 删除、批量删除、密钥类参数掩码显示。
- **字典管理**：字典类型与字典数据两栏，各自增删改、批量删除、分页。
- **字段管理**：按类别筛选、搜索、新增 / 编辑 / 删除供应器及其字段。
- **服务端管理**：服务端列表、重启 / 更新配置（mock 下为演示结果）。
- **默认角色模板**：搜索、分页、新建 / 编辑 / 删除 / 批量删除、恢复上次保存。
- **官方语音管理**：概览、价格版本（编辑草稿、发布、基于已发布版本新建草稿、同步状态）、人工备注、读取账单与人工结算。
- **记忆管理**：按设备 ID 筛选、分页、删除、清空该设备记忆。
- **记忆设置 / 习惯分析设置**：启用开关、服务地址、访问密钥、模型等参数的读取与保存、恢复已保存的设置。
- **习惯管理**：新增 / 编辑 / 删除、同步状态。
