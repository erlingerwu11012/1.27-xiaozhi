## 发现并修复的问题（本轮）

- 添加设备：验证码错误后提交按钮一直处于加载状态（原 AddDeviceDialog 同样存在）。现在请求层广播 `xn:request-failed`，弹窗立即结束加载并在验证码下方显示原因。
- 窄窗口面包屑前多一个“/”；长页面全页截图时侧栏底色只到首屏；侧栏收起时左边缘透出阴影。
- 记忆管理、习惯管理在服务异常时一直停在加载中（API 模块没有失败回调）：改为监听 `xn:request-failed` 显示“加载失败”。
- 设备管理、默认角色模板的表头“全选”在数据变化后不刷新（改为带作用域的表头插槽）。
