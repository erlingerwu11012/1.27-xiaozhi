# 烧录后的实机核对

服务端已切换，固件仍需你自行烧录。以下是核对思路，不是必须照念的口令。

- 音量：说“声音弄到二十”，再问“现在多大”；说“再大声一点”，应查到30。
- 亮度：说“弄到百分之九十”，应报实际4档；问“这是最高档了吗”，应说明最高5档；再亮一档应到5。
- 记忆：查饮料偏好，再明确改为绿茶，然后查新偏好；单纯追问不得改记忆。身份未确认应说明没听出是谁。
- 卡片：说“只把卡片关了，事情先留着”，应只收起展示；再问屏幕是否还有卡片，并检查事项仍存在。
- 闹钟：设一个几分钟后的闹钟，持续正常聊天跨过到点时间，观察是否触发；新固件可提供触发记录。
- 习惯：说“每天六点提醒”，应先询问早上还是晚上，不能直接替你选早上。
- 拍照：连续说“拍一下看看”“再拍一次”，核对识别结果及音频是否继续发送；失败要说明实际原因。
- 聊天：说“别开玩笑，直接回答”“别每句追问”，检查之后的回答是否遵从、是否重复播放。

同时保留固件串口COM7与`pm2 logs xiaozhi-server`日志，记下每次原话及时间。真实摄像头、扬声器、声纹误识率、存储和闹钟触发只能在设备上最终确认。本轮没有刷机或操作真实设备。
