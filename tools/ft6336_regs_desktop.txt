 | 读通道顺序操作说明
1. 写地址为0x31的“读通道顺序开始地址”寄存器00，如需要从中间某个通道开始读可输入需要的数据。代码：w 31 00
2. 读地址为0x37的通往顺序数据，一共读(“通道数”+“虚拟按键数”)个。代码：w 37 r X |  |  |  |  |  |  | 
 | 读Raw Data操作说明
1. 写地址为0x34的“读Rawdata开始地址”寄存器00，如需要从中间某个通道开始读可输入需要的数据。代码：w 34 00
2. 读地址为0x35的Raw Data 数据，一共读X个。一通道对应2字节，因此长度是 2*N(N为VA区+KEY区通道个数总和）。第2*N和第(2*N)+1为close mode 的rawdata.代码：w 35 r X |  |  |  |  |  |  | 
 | 读CB操作说明
1. 写地址为0x33的“读CB开始地址”寄存器00，如需要从中间某个通道开始读可输入需要的数据。代码：w 33 00
2. 读地址为0x39的CB 数据，一共读X个。一通道对应2字节，因此长度是 2*N(N为VA区+KEY区通道个数总和）。第2*N和第(2*N)+1为close mode 的rawdata.代码：w 39 r X |  |  |  |  |  |  | 
 | 读RS测试数据操作说明
1. 写地址为0x34的“读RS测试数据开始地址”寄存器00，如需要从中间某个通道开始读可输入需要的数据。代码：w 34 00
2. 读地址为0xF4的RS测试数据，一共读X个。一通道对应2字节，因此长度是 2*N(N为VA区+KEY区通道个数总和）。第2*N和第(2*N)+1为close mode 的rawdata.代码：w F4 r X |  |  |  |  |  |  |
