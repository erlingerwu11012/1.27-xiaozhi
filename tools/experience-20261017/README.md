# 2026-10-17 对话体验改进

范围：用户批准的前三项——口语表达、简单工具规划、记忆衔接。候选源在 `candidate/`，基于此前正式发布的 harness-repair-20261017-r2。没有修改固件。

## 实现

- `prompt_policy.py`：按本轮工具场景提供决策说明，普通聊天不附带完整业务规则；设置场景提供完整相对调节计划示例，保留补检入口和执行授权要求。增加口语和关系边界指导；仍有模板化附和，未宣称解决。
- `relative_plan.py` / `runtime.py`：对模型已明确授权的单一相对设置计划补齐完整步骤，统一“一点”的默认幅度；运行器仍读取实时值、计算和限幅，完整校验后执行，核验回执后才说成功。否定、歧义、多目标不走补齐捷径。
- `reply_composer.py` / `contracts.py`：记忆查询直接回答相关事实；空结果不证明从未说过或保存过；查询故障不转换成空库；失败原因未知时不猜故障原因。事实校验也用于流式输出前。
- `recent_memory.py`：相关召回优先显式事实和更正，限制为四条；完整事实分页和按 ID 读回保留原路径。失效身份、权限错误和查询故障不通过云回退绕过。
- `person_short_memory.py`：未达到压缩门槛的短会话也保留最近四条同一人员原话，单条160字，15分钟过期。与长期事实、执行回执分开；保留账号、人员、代次、智能体隔离，以及删除修订号和旧请求水位保护。
