# ESP32-S3 16MB 固件

本包修复 WebSocket hello 及视觉凭据绑定、USB摄像头有限恢复、人脸失败终态、TTS请求代次隔离、闹钟对象校验和人物OTA忙状态原因，修复精简格式化库下的64位日志字段打印，保持当前分区及用户数据布局。保留工作区已有显示和设备工具改动。

关闭占用串口的软件，解压后在 ESP-IDF PowerShell 中执行：

```powershell
./flash.ps1 -Port COM9
```

脚本先核对 SHA256，随后按清单地址写入；不执行 erase_flash，不写 NVS 或用户数据分区。若设备仍使用更早的分区布局，请先完成该布局对应的迁移，不能用本包代替迁移工具。

本包已编译并通过主机协议测试，尚未烧录，摄像头和实际音频效果仍待实机验证。
