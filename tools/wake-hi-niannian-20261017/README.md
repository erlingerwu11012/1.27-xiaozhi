# Hi，念念：本地唤醒与分区迁移

最终唤醒发音是“嗨，念念”。中文 MultiNet7 使用 `hai nian nian`，设备显示及 `listen/state=detect` 上报文字为 `hi，念念`，初始阈值为 0.20。

自定义唤醒先经过 AFE 回声处理，再进入 MultiNet。播报状态允许 AFE 支持的自定义检测，识别后复用原有停止播报、恢复聆听流程。原“你好小智”模型不打包。

16 MiB 新布局：应用仍在 `0x20000`，大小 `0x4F0000`；assets 在 `0x530000`，大小 `0x6D0000`；人物 spine 在 `0xC00000`，大小 `0x300000`；壁纸在 `0xF00000`，大小 `0x100000`。NVS、PHY、用户数据、bootloader 的地址和内容保持不变。

`migration.py --prepare --port COM11` 校验设备 MAC 和旧分区表，备份原人物/壁纸区域及设备配置。`--package` 校验编译结果、资源校验和与大小、保留的界面字体及人物文件，并创建 firmware 包。`--flash --port COM11` 校验备份和镜像哈希，写入四个数据镜像，验证后最后提交新分区表，再回读分区表和受保护配置以确认没有改变。

执行这些命令须使用 ESP-IDF 的 Python。迁移必须通过 USB，不能用旧版仅刷应用的发布脚本代替。`baseline/` 保存原设备数据，`firmware/manifest.json` 标识本次镜像，`evidence/` 保存检查和烧录结果。

智控台系统参数 `wakeup_words` 需追加 `hi念念` 并重新加载语音服务配置；服务端不需要声学检测或代码修改。若希望 ASR 识别出的“嗨念念”也走唤醒短回复，可以另加 `嗨念念`。本次固件工作不直接修改现网参数。

本地 C++ 测试注入模拟 AFE/MultiNet 输出，覆盖保留回声参考、单声道分帧、无效识别结果、重复回调和启停代次隔离；它们不测量真实声学识别率。实机测试须覆盖待机唤醒、播报中打断、不同距离和误唤醒。

2026-10-17 已在 COM11 完成本次迁移和烧录：四个数据镜像与分区表均通过 esptool 哈希校验，新分区表回读一致，NVS 和 userdata 回读哈希与迁移前相同。设备已执行重启。声学识别及打断的实机验收仍待用户测试，详见 `evidence/flash-result.json` 和 `evidence/validation.json`。
