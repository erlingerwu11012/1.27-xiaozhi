# 正式语音服务：禁用回复表情

## 已完成

- 正式服务器：`121.40.239.140`，PM2 服务 `xiaozhi-server`。
- 部署时间：2026-10-02 16:13:51（北京时间）。
- 正式入口：`https://www.realecho.cn/`；设备通道为同域名及 `api.realecho.cn` 的 `/xiaozhi/v1/`。
- 生成规则明确禁止 emoji、颜文字及句尾装饰表情。
- 语音编译器在分句前过滤残留 Unicode 表情和组合标记，字幕同时过滤。
- 纯表情尾段不创建合成任务，使用既有正常 LAST/stop 收尾路径。
- 固件无需重新烧录。现有设备重新连接后使用新规则。

## 测试及限制

部署前使用正式服务的 Python 环境完成 10 项离线回归测试，全部通过：

1. 两次日志中的单独眨眼表情尾段只输出一次正常 LAST。
2. 正文内表情被过滤，语音情感标签保留。
3. 无句末标点的正常文本仍合成并正常结束。
4. 全为表情的内容不创建上游任务，仍正常结束。
5. 跨流式分片的键帽表情被过滤，普通数字保留。
6. SSML 和换行保留，SSML 正文的表情被过滤。
7. 字幕不残留表情。
8. 主表达规则与最终表达规则都明确禁用表情。
9. 旧轮次的结束消息不结束新轮次。
10. 已中断的轮次不额外发送结束消息。

语法与正则编译通过；生产三个文件的 SHA256 与补丁一致。上线后服务持续在线，正式网站 HTTP 200，两条正式 WSS 通道均完成 TLS 连接及 HTTP 101 升级。

离线测试调用实际分句器和实际生产收尾方法，合成过程使用替身；域名检查未携带设备身份，也未调用模型或语音上游。尚未做真实设备对话的端到端验证，不能据此宣称所有原因造成的聆听延迟均已消除。
