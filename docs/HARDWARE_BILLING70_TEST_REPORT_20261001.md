## 毛利口径

新付费调用：售价=已验证官方成本÷0.30，因此 API 毛利=(售价−成本)÷售价=70%。按每批真实支付金额兑换点数，所以保留29/99元套餐仍按各自现金单价扣点。旧余额、赠点及跨新旧余额的旧部分不承诺70%毛利。支付手续费、服务器、优惠抵扣和运营成本不在 API 毛利中。
