# 自然对话与 MCP 执行改进：上线验收记录

2026-10-03 已更新正式服务，官网与 API 健康检查通过。这是原有提示词与执行入口的就地更新，没有新增产品版本或改变三步创建界面。历史文件名 `agent-base-prompt-v2.txt` 沿用既有加载路径。

## 本次修改

- 平台层：压缩重复要求，加入简短的自然接话示例；默认使用正常成人交流语气，取消额外卖萌、虚构动作、强制追问和无依据的记忆/天气描述。用户明确配置的可爱或其他风格仍有效。
- 人格层：保存的用户人格原文保持不变，只明确其用途为性格与表达习惯，不让人格决定工具权限、时间、对象或执行结果。真实设备人格哈希测试前后相同。
- 会话层：保留可信身份、时间、资料来源及功能模块；标出用户本轮原话。没有删除真实工具目录或参数 schema；复杂请求继续交给现有主模型理解。
- 执行入口：对有限的完整常用请求建立直接执行契约，校验当前真实能力及参数；实时预览缺失时不以拍照或其他工具代替。正文里的 JSON/XML“调用”既不执行，也不直接播报为已完成。
- 结果反馈：音量、亮度等控制依据业务回执生成事实反馈；接受、失败、超时和完成分别处理。相同写请求在本轮内去重，超时后不自动重发可能已经生效的操作。
- 多轮任务：待补时间的提醒按会话与可信身份隔离，保留日期；“九点”先问上午或晚上，尚未执行时允许纠正或取消。任务过期、换人或换话题时清除。最近已确认的控制支持有限省略表达。
- 普通对话：明确问候或风格交流不会执行工具。现有不支持 `tool_choice` 参数的模型接口继续兼容。流式字幕、语音和历史使用同一份经过校验的文本；没有新增二次润色模型。

## 测试环境问题与处理

一次设备重连发生在测试进程重启的监听空窗：nginx 连接测试端口被拒绝，返回 502，固件未收到 WebSocket 握手响应头。与证书及 Wi-Fi 故障无关。

最终聊天检查又发现测试进程没有继承正式启动脚本注入的内部计费认证环境，主模型签名失败被 SDK 表现为连接错误。已从正式运行进程的受信环境补齐测试配置，密钥没有输出或提交；先启动并确认替换进程监听，再切换单设备路由。修复后四句实际链路全部通过。验收脚本已将服务降级错误文本判为失败，避免只因“有回答”而误算成功。

## 仍有的边界

本次保证的是已适配契约和上述样本的执行结果，不是“理解所有自然语言”。有限语法之外主要依赖现有主模型，否定、指代和完成话术检查也有覆盖边界；缺少信息时可能拒绝或补问。没有承诺对所有新说法都正确执行，更没有保证所有普通聊天事实都正确。

幼龄口癖检查结合人工阅读，只能说明当前默认风格的测试表现。部分回复仍会有模板化安慰、追问或不够严谨的科普措辞；用户主动配置的可爱人格不会被平台抹去。物理麦克风、环境噪声、口音和大规模长期延迟另需实际采样，不能由合成录音或 12 组配对代替。

主要非敏感证据保存在本仓库 `docs/natural-dialogue-20261003/`：回归、模型原始与校验后结果、聊天重复检查、真实 ASR/MCP、硬件、最终聊天、延迟、旧基线对比及上线核验。首轮失败记录仍保留在服务器测试目录，未用成功记录抹去。
