# 工具事实与自然对话修复记录

正式域名：https://www.realecho.cn/ 。本次仅发布已验证的工具回执、背景标注与纯正文语音规则，默认模型保持 qwen3.8-flash / 0.4。没有改用户人格，没有二次润色，也没有改前端或数据库配置。

## 已发布

- 对 get_world_time 的完整回执核验时区、日期、星期与 UTC 偏移，直接按回执播报当地日期及时间。不再让主模型重新计算或自由转述。格式缺失或冲突就说明不能确认。保持原始工具调用与回执的配对历史。
- 设备状态中的音量、亮度数值直接由合法回执生成。调整、便签和提醒仍要求业务完成证据，接收请求不等于完成。概念解释及开放式工具结果继续走原有主模型路径，不从模型正文执行工具。
- 服务端 MCP 的 isError 回执明确按错误处理，不能因文本包含成功字样而宣布成功。
- 历史摘要、记忆明确标注为背景参考，不得朗读或续写内部摘要任务。源码核查与上次合成测试没有发现摘要指令串入聊天的证据，不能声称已确认这一根因。
- 主模型不再收到官方情绪/声音动作标签白名单引导。要求直接口语正文。TTS 对旧标签的解析、字幕清理和中断恢复能力仍保留。

## 候选及模型对比

调整后的聊天规则、独立新话题和边界场景已完成真实模型测试，但聊天候选没有覆盖正式规则。测试包含旧规则同输入基线、Flash、Max、Plus，新话题复测，以及同一个 Max 主模型开启思考的8轮对照；共174次主模型对比调用。所有成功与失败输出都保留。

测试过程先采用全账户额度保护，该指标同时包含账户的其他调用，曾两次暂停。断点及原始输出保留；剩余部分改用本次测试自身的调用数和token上限，最终轮总上限40次，没有修改账户额度。

Max 非思考模式的事实边界相对更稳定，但仍有多余建议、对用户经历和心理的推断。思考模式没有解决这些问题，单轮总响应约2.7—10.6秒，还出现未经提供的生活细节。没有足够证据将其判为聊天验收通过，因此不切换正式默认模型。

## 验证与限制

候选及发布后正式源码的233项断网回归均通过，覆盖实际聊天处理器的TTS队列、调用/回执配对、不同城市与时区、状态数值、概念解释、权限、字幕和旧标签兼容。

候选与发布后的正式默认模型各完成5轮合成音频：官方TTS生成测试输入，真实ASR识别，实际 ConnectionHandler 处理，真实只读MCP查询，再调用官方TTS生成回复。两组的伦敦、东京、上海时间播报都与工具回执一致。音频链路连通不等于聊天质量通过。

发布后正式Flash第1句仍把“刚买了书架、还没发货”回答成“书架还没挑，先惦记上了”。这是明确事实误读，记录没有隐藏。因此本次不能宣称自然聊天已经达标。

用户表示暂不方便实机验收，因此没有测试物理麦克风、设备扬声器、Wi-Fi和实机WebSocket链路，也没有调整硬件或创建提醒。网站及公开API返回200，三个相关PM2服务online；发布过程保留源码备份与自动回滚。
