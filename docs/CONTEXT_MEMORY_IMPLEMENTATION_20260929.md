## 2. 现在怎样工作

1. 音频轮次开始时冻结账号、人物、智能体、目录版本、默认代次和采集时间。ASR、回答及异步存档沿用该快照。
2. 固定规则和用户角色设定只构建一份前缀；可信人物、时间、天气、摘要和当前对话作为动态资料。生成提示词不再写死爸爸等当前聊天对象昵称。
3. 对最终请求的全部输入估算token，包括工具定义、调用参数、工具结果和协议开销。缓存命中不抵扣上下文。
4. 接近16万时后台准备摘要；达到18万且摘要验证通过后切换，尽量降到约5万；达到20万保护线时限制本次请求视图。
5. 需要回顾历史时主模型调用`memory_search(query)`：先查同人最近24小时的已有文字存档；本地不足且选择长期模式时，才查百炼。
6. 百炼仍按人物每天北京时间03:00合并有效新材料。压缩本身不触发Add。习惯副模型继续分析可信行为及真实工具执行结果。

### 身份和录入素材

| 情况 | 原语音文字存档 | 当前对话 | 个人记忆、检索及习惯 |
|---|---|---|---|
| 没有有效声纹 | 当前默认人物及代次 | 默认人物上下文 | 按所选记忆模式使用 |
| 识别出已绑定成员 | 稳定人物ID | 对应成员上下文 | 仅该成员 |
| 已有声纹但未识别本轮 | 人物ID为空，状态unknown | 同连接连续临时聊天 | 不保存个人摘要，不查个人存档或百炼，不进入个人习惯 |
| 旧协议缺可信归属 | 标为legacy_unowned | 不据此推定人物 | 可选作录入素材，不导入个人记忆 |

例如爸爸已绑定、儿子未绑定：儿子的录音仍能出现在声纹录入选择框中；“讲个故事→再讲一个”可以在同次未知身份聊天中接续。以后识别出爸爸时不会带入儿子的临时上下文。选一条儿子的录音录入声纹，只创建模板，不追认此前其他未知记录。

未知身份在识别出成员、目录或模式改变、会话超时或断连时失效；默认连续间隔为120秒。不能凭临时上下文区分两个未录声纹的人。语音文字上传仍受现有存档配置控制。

## 3. 压缩参数和可靠性

生产`main/xiaozhi-server/config.yaml`的`context_compress`已采用独立参数，实际配置加载器合并智控台配置后核验生效：

| 参数 | 已发布值 |
|---|---:|
| input_limit_tokens | 200000 |
| prepare_tokens | 160000 |
| trigger_tokens | 180000 |
| target_tokens | 50000 |
| keep_recent_rounds | 4 |
| summary_target_chars | 3000 |
| summary_max_chars | 6000 |
| summary_batch_tokens | 24000 |

计数是完整请求的保守估算，含4/3填充；上游实际prompt用量存在时用于向保守方向校准。模型输入和总上下文限制分别检查，另为输出预留空间。20万不是账单实计，也不是承诺模型精确token化后的绝对值。

- 每会话只允许一个摘要任务，服务端最多两个活跃摘要任务；没有空位时继续聊天，后续再尝试。
- 摘要输入含上一份有效摘要与待移出的完整文本。长消息切成带来源ID的连续片段，每批完整估算不超过24000；取消此前只读前500字的方式。
- 摘要必须为7组字符串数组：话题、事实、日期关系、约定、待办、更正、实际业务结果。JSON错误、空内容、超过6000字符或压缩无效均拒绝。
- 提交前比较摘要版本、来源消息ID及完整来源哈希。旧任务、被更正的来源及已退役身份不能提交。至少保留最近4个完整轮次及当前轮次，工具请求和结果配对保留。
- 摘要失败时保留原文和旧摘要。20万保护只缩小本次发送视图；必要内容极大时保留首尾并标记省略，完整原文仍在会话内。
- 固定规则与必需工具定义自身超过模型预算时返回真实失败，不能虚称仍保留全部内容且调用成功。
- 明确上游上下文超限最多重试一次，仅限尚未输出内容；复用原工具结果，不重新执行工具或重播语音。
- 已移除50条消息提前硬删除、普通长assistant/tool消息提前截断等旧运行流程。
- 约5万是目标。固定提示词、动态资料或最近必要轮次过大时可能超过目标，仍受20万保护。摘要是有损整理，不能保证全部措辞和细节。

压缩摘要只作为参考资料，不具有工具执行权限。语音文字存档和百炼事实不会因压缩而删除；存档保存期限沿用原设置，24小时仅为自动近期检索范围。

- 同账号、同人物、同智能体、同代次、最近24小时查询，中文词片段与英文词匹配，结合时间排序及必要相邻语句。
- 复用既有行为表中的实际成功/失败记录，不建立第二份业务库。旧行为表没有智能体字段，只有与同账号、人物、代次、原设备及原轮次的可信存档关联后才召回；无法证明原智能体的事件不猜归属。结果明确标注成功或失败，更正后关联存档失效，旧业务证据同步不可召回。
- 最多5组本地结果；提取匹配附近片段，返回文本最多3000字符。弱命中不作为确定事实注入。
- 本地可靠命中直接返回；短期模式不调用百炼。长期云端Search仍每轮最多一次、top_k=5、事实最多1500字符。
- 人物未知、身份已失效或受到明确抑制时禁止个人检索，不跨人降级。
- 保留最近50条用户音频的选择和试听；列表不要求人物ID非空。单条文字、播放凭证及声纹注册补账号归属检查，播放凭证有效期300秒。
- 首次声纹注册先读取样本、注册验证，再删除默认资料。独立声纹向量不依赖旧聊天音频持续存在。
- 更正或忘记立即失效旧摘要、旧召回来源与缓存。短期更正为本地操作，不创建百炼实体；后续切长期才按有效归属同步抑制。
- 迟到上报保留可信原始归属，但更正前的旧来源不得参与召回。退役人物及旧默认代次的上报被拒绝。
- 默认/成员删除同时清理有归属的存档、音频、摘要、近期来源和任务；未知素材不因注册某个成员而自动归给他。
- 跨设备更正会增加人物摘要修订号；旧连接关闭时先验证原修订号，模型整理后写入前再验证，不能恢复旧摘要。
