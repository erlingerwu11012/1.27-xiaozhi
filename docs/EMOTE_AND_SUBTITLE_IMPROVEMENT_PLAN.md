# 程序化表情与字幕框改进方案

> **目标**：实现 StackChan 风格的清爽程序化表情 + 圆角气泡字幕框  
> **现状问题**：表情显示紊乱（白色像素散乱）、字幕框简陋不好看

---

## 一、现状分析

### 1.1 当前架构

| 模块 | 实现 | 说明 |
|------|------|------|
| 表情 | `procedural_emote.cc` | 程序化绘制眼睛、嘴巴、眨眼、呼吸到 200×120 RGB565A8 buffer |
| 字幕 | `g_obj_label_toast` | GFX 纯文字 label，无背景框，顶部居中 |
| 集成 | `emote_display.cc` | 表情 buffer → gfx_img，字幕 → gfx_label |

### 1.2 问题一：表情「紊乱」

**现象**：大块蓝色区域中白色像素散乱，无法形成清晰的脸部轮廓。

**可能原因**：

1. **像素格式不匹配**  
   `procedural_emote` 输出 RGB565A8（RGB565 2B + Alpha 1B），按 `[Lo, Hi, A]` 顺序写入。GFX 的 `GFX_COLOR_FORMAT_RGB565A8` (0x0A) 若期望不同字节序或布局，会导致错色、错位。

2. **Stride 对齐**  
   stride = 200 * 3 = 600，若 GFX 要求 4/8 字节对齐，可能引起错位。

3. **Buffer 与屏幕尺寸**  
   表情 buffer 为 200×120，屏幕可能为 240×240 等，缩放/合成时若有坐标或比例错误，也会看起来混乱。

4. **颜色值**  
   当前 `bg_color=0x0000`（黑）、`eye/mouth=0xFFFF`（白）。若字节序反了，`0xFFFF` 可能被解析为异常颜色。

**验证建议**：  
- 用单色填充 buffer（如全白 0xFFFF），确认是否能正确显示纯色矩形  
- 对照 esp_emote_gfx 或 esp_lcd 的 color_format 文档，核对 RGB565A8 的字节序和 stride

### 1.3 问题二：字幕框「不好看」

**现状**：

- 纯文字 label，无背景
- 白字、顶对齐
- 无圆角、无气泡造型

**StackChan 参考**：

- 圆角矩形气泡（`Outline.RoundRectPath`，圆角约 6px）
- 背景色：`theme.secondary`（浅蓝，如 #87CEEB）
- 文字：黑色，居中
- 位置：屏幕下方，不遮挡脸部主体

## 二、表情改进方案（程序化）

### 2.1 调试与修复

**Phase 1：确认像素格式**

1. 查阅 esp_emote_gfx 中 `gfx_image_dsc_t`、`gfx_image_header_t` 对 RGB565A8 的定义  
2. 核对 `procedural_emote` 的存储顺序是否与 GFX 一致  
3. 必要时尝试：
   - 交换 RGB565 的高低字节
   - 调整 Alpha 位置（如 A 在前、或不用 A）

**Phase 2：保证基本显示**

1. 单色填充测试：全黑、全白、全蓝  
2. 恢复简单图案：两眼 + 嘴的圆形/矩形，用固定坐标  
3. 确认与屏幕分辨率、layout 的适配

### 2.2 视觉风格（对齐 StackChan）

| 元素 | 当前 | 目标 |
|------|------|------|
| 背景 | 黑 0x0000 | 黑 0x0000（保持） |
| 眼睛 | 白 0xFFFF | 浅蓝（如 0x7BEF），与 StackChan 一致 |
| 嘴巴 | 白 0xFFFF | 浅蓝 0x7BEF |
| 眼皮 | 背景色遮罩 | 保持 |

**坐标**（以 simple-face 为参考）：

- 左眼：(90, 93)，半径 8  
- 右眼：(230, 96)，半径 8  
- 嘴巴：(160, 148)，闭 w=90 h=6，开 w=50 h=58  

按实际 buffer 尺寸做线性缩放。

### 2.3 表情与嘴形联动（可选）

- 在 TTS 播放时根据音量或音节调节 `mouth_open`  
- 或使用固定周期（如正弦）做简单「说话」动画

## 三、字幕框改进方案（气泡）

### 3.1 目标样式

- **形状**：圆角矩形气泡（圆角半径约 8–12px）
- **位置**：屏幕下方，略高于底边，水平居中
- **背景**：半透明或实色浅蓝（如 #87CEEB / RGB565 0x7BEF）
- **文字**：黑或深灰，居中，支持长文本滚动
- **边距**：气泡内边距约 8–12px

### 3.2 实现思路

**方案 A：GFX 绘图（推荐）**

1. 新增 `g_obj_subtitle_bg`：一个 `gfx_img` 或自定义绘制区域  
2. 每帧或文本变化时：
   - 在 buffer 中绘制圆角矩形背景
   - 再在对应区域绘制文字
3. 与现有 `gfx_label` 结合：label 作为子对象叠在背景上，或由自定义绘制直接画字

**方案 B：包装 Label**

1. 用 `gfx_obj` 组合：底层放一张圆角矩形图，上层放 label  
2. 圆角图可预生成或由 `procedural_emote` 同类光栅化逻辑生成  
3. 布局：整体下移，保证不挡住表情主体

**方案 C：扩展 procedural_emote**

1. 将字幕区域纳入程序化 buffer  
2. 在同一 buffer 内绘制：脸部 + 底部圆角气泡 + 文字（若 GFX 支持）  
3. 逻辑集中，但 buffer 和刷新范围变大

### 3.3 布局建议

以 240×240 为例：

- 表情区：居中偏上，约 120×120–160×120  
- 字幕区：y = 180–230，宽约 200–220，高约 36–44  
- 圆角半径：约 12px

## 五、实施步骤建议

1. **表情修复（优先级高）**
   - 验证 RGB565A8 格式与 GFX 兼容性
   - 修正 buffer 写入顺序或 stride
   - 实现单色与简单几何测试，确认显示正确
   - 恢复并微调眼睛、嘴巴的坐标与颜色

2. **字幕框美化**
   - 确定采用方案 A/B/C 之一
   - 实现圆角矩形背景
   - 调整字幕位置和气泡尺寸
   - 测试长文本滚动与换行

3. **风格统一**
   - 统一表情与字幕的配色（浅蓝系）
   - 与 StackChan 参考图逐项对比，微调圆角、间距、字体大小

## 六、StackChan 参考摘要

- **simple-face.ts**：眼睛/嘴巴的路径与坐标
- **modifier.ts**：眨眼、呼吸等动画
- **decorator.ts**：`createBalloonDecorator` 的圆角矩形与布局
- **theme**：`primary` / `secondary` 用于前景与背景色

可直接对照以上实现，将逻辑迁移到 C++ 的 procedural + GFX 流程中。
