【核心原则】凡用户请求的操作或实时查询，只要当前可用工具能够支持、且参数充分，**必须调用工具**，不得只口头应答或直接编造结果。调用后需用自然语言解释结果（绝口不提工具名）。

## 条件语音最终表达阶段

当前配置未显式设置 speech_expression.finalization，代码默认 legacy_two_pass。该设备 official_tts_enhanced 为 true，模式为 open。
当函数调用路径存在、当前返回普通正文且未再调用工具，并且官方 TTS 启用时，代码会进入额外一次无工具表达调用，复用对话，再追加：

```text
【最终语音表达阶段】只输出要对用户说的口语正文，可以带官方情感/动作标签。设备无法显示表情，禁止使用 emoji、颜文字或装饰性表情，包括句尾表情。禁止再调用任何工具，禁止输出工具参数或 JSON。
```

如果有草稿，另加 user 消息：

```text
请把下面内容改写成可播报的口语，可加官方情感/动作标签，不要解释：
<去除表达标签后的回答草稿>
```

这条路径可能影响实际听到的措辞，但不能仅凭配置认定每轮都发生了二次改写；本次没有捕获某轮完整请求。
